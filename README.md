1. اضغط زر **Download APK** أعلاه.
2. افتح الملف `enjazi.apk` بعد التحميل.
3. لو ظهرت رسالة عن التثبيت من مصدر غير معروف، اضغط **الإعدادات** واسمح للمتصفح بالتثبيت، ثم ارجع واضغط **تثبيت**.

- **قائمة المهام:** تاريخ ووقت، أولويات، تصنيفات بالاسم الذي تختاره، مهام فرعية، تكرار، وتذكيرات.

- **المظهر:** فاتح، داكن، أو مريح للعين، بالعربية والإنجليزية وبثلاثة أحجام للخط.
